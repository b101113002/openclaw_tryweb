# 實戰專題｜把 OpenClaw 放進真實工作流程

這裡不以功能清單作為學習終點，而是從一個具體問題開始：你希望減少哪一段重複工作？助理需要哪些資料？哪些步驟可以自動化？哪些環節必須由人確認？

每個專題會逐步補上情境、流程圖、設定方式、測試資料、驗收條件、費用與權限提醒。尚未完成的專題會標示規劃狀態，不把入口頁當成已完成教學。

## 專題教材的完成標準

每個正式專題至少要包含：使用情境與不適用情境、資料流向、必要帳號或模型費用、逐步設定、權限風險、測試方式、預期輸出、故障排除與官方文件來源。

開始實作前，建議先完成[OpenClaw 入門](/guide/)並熟悉[安全使用邊界](/guide/safety/)。
