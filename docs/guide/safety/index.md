# 07｜安全與資料邊界

本機 AI 能減少把提示內容送到雲端模型的需求，但不代表所有資料都一定留在電腦。只要啟用網路搜尋、第三方工具、外部 API 或遠端存取，就要重新確認資料流向。

## 1. 區分本機與外部連線

| 動作 | 是否需要網路 | 可能接觸的外部服務 |
|---|---|---|
| 已下載模型的本機聊天 | 通常不需要 | 無 |
| 本機文件索引與問答 | 可本機處理 | 取決於是否使用雲端 Embedding |
| 下載模型或更新程式 | 需要 | 模型發布平台、軟體發布來源 |
| 網路搜尋 | 需要 | 搜尋引擎與原始網站 |
| 網頁擷取 | 需要 | 被瀏覽的網站 |
| 雲端模型 Provider | 需要 | 模型供應商及其服務條款 |

使用本機模型時，也要確認 Embedding、語音、圖片處理及搜尋功能沒有意外指向雲端服務。

## 2. 文件與個資

- 初次測試使用公開資料或虛構資料。
- 不要直接把病歷、身分證號、銀行資料、密碼或未公開研究文件匯入未檢查的工作區。
- 檢查文件儲存路徑、備份路徑與工作區的存取權。
- 不要把 AnythingLLM 的儲存資料夾、模型檔案或本機服務連接埠公開到網際網路。

## 3. Agent 與提示詞注入

Agent 搜尋的網站、讀取的 PDF、郵件與程式碼都可能含有惡意指令，例如要求 AI 忽略原本規則、洩露資料或執行命令。

- 搜尋與整理外部資料時，優先使用唯讀工具。
- 外部資料不能授權 Agent 改變系統規則或取得額外權限。
- 不讓讀取網頁的 Agent 同時持有不必要的 Shell 與檔案刪除能力。
- 重要輸出保留來源與引用，不接受沒有證據的結論。

## 4. 高影響操作要有人確認

以下操作不要預設自動執行：

- 寫入或覆蓋重要檔案。
- 刪除資料。
- 寄送 Email、聊天訊息或公開貼文。
- 付款、購買或變更帳號／系統權限。
- 執行不明 Shell 指令或安裝第三方 MCP／Skill。

先讓 Agent 產生計畫或草稿，再由使用者確認後執行。

## 5. 本機服務不要直接公開

AnythingLLM、Ollama、SearXNG、OpenClaw Gateway 等服務預設只應供本機或可信任的內部網路使用。需要跨裝置存取時，先使用 VPN、Tailscale 或 SSH 隧道等受控方式，不要直接將管理介面、Token 或 API 端點暴露在公網。

## 6. 安全檢查清單

- [ ] 模型與 Embedding 使用本機服務。
- [ ] 我知道網路搜尋會將查詢送到哪個搜尋引擎。
- [ ] 工作區沒有不必要的敏感資料。
- [ ] Agent 只啟用完成任務必要的工具。
- [ ] MCP Server 與 Skills 已確認來源。
- [ ] 寫入、刪除與對外傳送保留人工確認。
- [ ] 本機服務沒有不必要地公開到網際網路。
