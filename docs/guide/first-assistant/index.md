# 03｜完成第一次本機對話

現在你已經有本機 AI 對話介面。本課要完成三件事：確認模型確實在本機運行、建立自己的工作區，以及用一份不含敏感資料的文件測試知識庫。

## 1. 確認目前使用的是本機模型

在 AnythingLLM 的模型設定或聊天視窗，確認目前選擇的是內建本機模型引擎及已下載的模型。

請不要只看模型名稱。還要確認：

- 模型來源是本機，不是 Cloud Provider。
- 不需要 API Key。
- 關閉網路後，單純文字聊天仍能回應（前提是模型已完整下載）。
- 第一次下載模型需要網路，但後續本機推論不必連線到模型供應商。

## 2. 建立工作區

建議依主題建立不同 Workspace，例如：

| 工作區名稱 | 用途 | 建議資料 |
|---|---|---|
| 個人研究 | 閱讀研究文章、整理文獻 | 公開論文、自己的筆記 |
| 課程筆記 | 查詢教材與學習資料 | 課程講義、公開教材 |
| 專案工作 | 整理開發決策與工作紀錄 | 專案文件、README |
| 日常助理 | 一般文字對話與規劃 | 非敏感的個人偏好 |

不同工作區可以讓對話與文件脈絡比較容易管理。不要把所有私人資料一次匯入同一個工作區。

## 3. 測試一般聊天

先用無個資問題測試模型：

```text
請用繁體中文解釋「本機大型語言模型」是什麼。
請分別說明模型檔案、推論引擎與聊天介面的差別。
最後列出三個我可以自行驗證的重點。
```

如果模型能正常回覆，表示基本本機聊天可用。這不等於 Agent 工具、網路搜尋或文件檢索也已通過測試。

## 4. 測試文件問答

1. 找一份公開或不含敏感資料的 PDF／Markdown 文件。
2. 將文件加入指定 Workspace。
3. 等待文字擷取與索引完成。
4. 用文件中確實存在的資訊提問。
5. 再問一個文件沒有提供答案的問題，確認模型是否能承認資料不足。

測試提示詞：

```text
請只依據此工作區已匯入的文件回答。
每個重要結論請指出來源文件或引用片段。
若文件沒有提供答案，請明確說明「文件中沒有足夠資訊」，
不要用模型自己的常識補成文件結論。
```

這可以幫助你理解 RAG（檢索增強生成）：系統先從文件中找出相關內容，再把內容交給模型組織回答。

## 5. 確認資料是否留在本機

AnythingLLM Desktop 官方以本機資料保存為主要使用情境，但實際資料流仍取決於你的設定。請注意：

- 本機模型推論與本機文件索引可在自己的設備執行。
- 模型下載時會連線到模型檔案來源。
- 啟用網路搜尋時，查詢會送到搜尋引擎。
- 若你自行加入雲端 Provider、外部 MCP 或其他第三方工具，資料流也會隨之改變。

## 6. 完成檢查

- [ ] 不連接雲端模型時，本機模型仍能回答。
- [ ] 我建立了至少一個 Workspace。
- [ ] 我能用文件內容提問並看到來源。
- [ ] 當文件沒有答案時，模型不會被要求硬猜。
- [ ] 我知道哪些操作會將資料送到外部網路。
