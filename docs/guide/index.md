# 本機開源 AI 入門｜從零建立自己的 AI 工作站

本課程的目標不是讓你註冊更多 AI 網站，而是把必要的 AI 能力盡量放在自己的裝置上：本機模型、本機對話室、文件知識庫、網路搜尋與 AI Agent。

## 我們的預設工具組合

| 層級 | 預設選擇 | 用途 | 是否需要外部帳號 |
|---|---|---|---|
| 對話介面與工作區 | AnythingLLM Desktop（MIT） | 聊天、文件問答、Agent 操作 | 不需要建立雲端帳號 |
| 本機推論 | AnythingLLM 內建引擎（Lemonade／llama.cpp） | 在自己的電腦載入模型 | 不需要模型 API Key |
| 本機模型 | Google Gemma 4、IBM Granite 4.0 | 文字與工具任務 | 公開權重可下載；依個別模型授權使用 |
| 網路搜尋 | AnythingLLM 內建 DuckDuckGo | 讓 Agent 搜尋網頁 | 不需 API Key，但仍受上游服務可用性影響 |
| 進階搜尋 | SearXNG（AGPL-3.0） | 自行架設中繼搜尋服務 | 不需商業搜尋 API Key；上游搜尋引擎可能限流 |
| 進階 Agent | OpenClaw（MIT） | 多渠道、排程、工具路由與多 Agent | 可連接本機模型；不必先用雲端模型 |

這套入門路線以一套桌面程式為主，不要求先安裝 Docker、資料庫、向量資料庫或多個雲端 SaaS。當你真的需要進階能力時，再加裝對應服務。

## 我們的篩選原則

- **軟體授權明確**：主教學優先採 MIT、Apache-2.0、AGPL-3.0 等開源授權。
- **模型來源透明**：優先 Google、IBM 等非中國開發團隊發布、授權清楚的公開權重模型。
- **不把開放權重誤稱為完整開源**：模型權重可下載，不代表訓練資料與完整訓練流程也都公開；每個模型都會個別說明授權範圍。
- **減少外部註冊**：不以 OpenAI、Anthropic、Google Cloud、搜尋 API 或其他需要註冊與申請額度的雲端服務作為必修。
- **不把免費額度當成零成本**：免費雲端服務可能改變規則或限流；優先使用本機推論。
- **維持來源查核**：AI 搜尋到的內容是線索，不是證據。重要資訊要回到原始網站核對。

## 網路搜尋的現實限制

本機執行模型不代表網際網路搜尋也能完全離線。若要查詢最新網頁，搜尋字詞必須送到搜尋引擎或上游網站。自架 SearXNG 可以讓搜尋聚合服務由自己管理，免去商業 API Key，但它仍要向公開網路上的搜尋引擎取回資料；這些引擎仍可能限流、要求 CAPTCHA 或改變政策。

因此本站的目標是「不需要多個帳號與商業 API 額度」，而不是宣稱網路搜尋可以永久無限制或完全不接觸第三方服務。
