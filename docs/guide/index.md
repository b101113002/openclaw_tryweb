# OpenClaw 入門｜從零建立自己的 AI 助理

這套課程不是把其他網站的章節逐段翻譯，而是重新依照「初學者真正需要完成的任務」安排。你會先弄懂 OpenClaw 的元件，再安裝、完成第一個對話，最後建立基本安全邊界。

## 這套課程會帶你完成什麼？

- 理解 OpenClaw 如何串接模型、聊天平台與工具，以及 Gateway 在其中扮演的角色。
- 確認電腦環境、安裝方式與模型連線選擇，避免安裝到一半才發現硬體或權限不足。
- 完成第一次啟動，確認 Gateway、控制介面與模型回覆都正常。
- 知道哪些資料可以交給 AI、哪些工具需要限制，以及如何降低提示詞注入造成的風險。

## 我們的教學方式

每個實作單元會盡量維持相同結構：

1. **這一課要完成什麼**：先定義可以驗收的成果。
2. **開始前準備**：列出版本、帳號、硬體與費用需求。
3. **跟著操作**：提供命令、設定位置與每一步的原因。
4. **確認成功**：給出可自行檢查的結果，不以「看起來有跑」當作完成。
5. **常見問題與回復方式**：說明錯誤可能原因，以及如何安全回復。
6. **延伸閱讀**：連到官方文件與其他可信來源，並標示查核日期。
