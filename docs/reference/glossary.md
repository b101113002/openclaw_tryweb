# 繁體中文術語表

本網站以台灣繁體中文為主，專有名詞首次出現保留英文。產品名稱、CLI 指令、模型名稱、設定鍵與程式碼原則上不翻譯。

| 英文 | 建議譯法 | 說明 |
|---|---|---|
| Local AI | 本機 AI | 主要推論工作在自己管理的電腦或主機執行。 |
| Local inference | 本機推論 | 由本機 CPU／GPU 執行模型運算。 |
| Open weights | 公開權重 | 模型權重可取得；不代表訓練資料與完整訓練流程都公開。 |
| AI chat UI | AI 對話介面 | 使用者與模型對話、管理工作區與文件的介面。 |
| Agent | 智能體／Agent | 能依目標規劃並使用工具完成任務的系統。 |
| RAG | 檢索增強生成 | 先檢索文件或資料，再將相關內容交給模型回答。 |
| Workspace | 工作區 | 用來管理特定專案的對話、文件與 Agent 設定。 |
| MCP | Model Context Protocol | 連接 AI 應用程式與外部工具／資料來源的開放協定。 |
| SearXNG | SearXNG 中繼搜尋 | 自架的開源中繼搜尋引擎，可彙整多個公開搜尋來源。 |
| Search engine | 搜尋引擎 | 負責索引或檢索公開網頁的服務。 |
| Scraping | 網頁擷取 | 從指定網頁讀取文字或結構化內容。 |
| Gateway | 閘道（Gateway） | 管理連線、路由與服務入口的元件。 |
| Skill | 技能（Skill） | 將特定任務流程或知識封裝成可重複使用的能力。 |
| Tool | 工具 | Agent 可呼叫的功能或操作介面。 |
| Sandbox | 沙箱 | 用來隔離執行環境與限制權限的安全機制。 |
| API Key | API 金鑰 | 用於驗證 API 存取權限的憑證。 |

## 用語原則

- 「開源軟體」描述軟體程式的授權與原始碼開放情況。
- 「公開權重模型」描述模型權重可以取得，仍須閱讀各模型授權。
- 不使用「完全私有」或「完全離線」來描述含網路搜尋、模型下載或外部 MCP 的工作流程。
- 免 API Key 不等於無限流量；公開搜尋引擎可能限流或要求 CAPTCHA。
