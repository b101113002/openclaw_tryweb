# 繁體中文術語表

本網站以台灣繁體中文為主，專有名詞首次出現保留英文，避免把產品名稱、CLI 指令或程式碼翻譯掉。

| 英文 | 建議譯法 | 說明 |
|---|---|---|
| Agent | 智能體 | 能依目標規劃並執行動作的軟體系統。 |
| AI Agent | AI 智能體 | 具備模型推理、工具使用與任務執行能力的智能體。 |
| Gateway | 閘道（Gateway） | 接收、轉送或管理請求的入口層。 |
| Skill | 技能（Skill） | 將特定任務流程或知識封裝成可重複使用的能力。 |
| Tool | 工具 | Agent 可呼叫的功能或操作介面。 |
| Runtime | 執行環境 | 程式或 Agent 實際運作的環境。 |
| Prompt | 提示詞 | 提供給模型的指令與上下文。 |
| Workflow | 工作流程 | 多個步驟或任務的串接方式。 |
| Sandbox | 沙箱 | 用來隔離執行環境與限制權限的安全機制。 |
| Token | Token／詞元 | 模型處理文字時使用的基本單位。 |
| CLI | 命令列介面 | 透過文字命令操作軟體的介面。 |
| API Key | API 金鑰 | 用於驗證 API 存取權限的憑證。 |

若同一技術名詞在不同上下文有不同譯法，將在本表及更新紀錄中說明。
