# 第 1 章｜AutoClaw 一鍵安裝（第三方桌面方案）

> 本章介紹上游教材所列的 AutoClaw 桌面應用程式。它是第三方產品，不是 OpenClaw 官方安裝程式；若你希望自行掌握模型、資料處理位置與 API 費用，可以直接跳到[第 2 章：手動安裝 OpenClaw](/adopt/chapter2/)。

<Badge type="warning">第三方服務／選讀</Badge>

## 閱讀前請先注意

原始教材介紹的 AutoClaw 由中國廠商提供，註冊流程涉及中國手機門號，且上游文件所列內建模型與生態包含中國開發的模型。這與本網站「優先採用非中國開發模型、開源工具及本機部署」的原則不完全一致。

因此，本章保留作為上游教材的翻譯與方案參考，但**不將 AutoClaw 列為本站首選，也不要求讀者註冊、充值或使用其內建模型**。若你選擇試用，請先自行核對目前的服務條款、支援地區、收費方式、資料保存政策及模型實際運算位置。產品頁面所宣稱的本機資料保存，不等於模型推論或所有外部服務都在本機完成。

原文提到的免費點數、預裝技能數量、模型名稱及介面項目都可能隨版本或促銷活動改變；以下僅作為上游教材版本的功能翻譯，不代表目前仍提供相同方案。

## 1. 安裝與啟動

上游教材列出的流程如下：

1. 前往 [AutoClaw 官方產品頁](https://autoglm.zhipuai.cn/autoclaw)，查看目前是否提供適用於 macOS 或 Windows 的安裝程式。
2. 下載安裝程式，依作業系統指示完成安裝。
3. 開啟應用程式，依其當前註冊流程建立帳號。
4. 閱讀服務條款、隱私政策與權限要求，再決定是否繼續使用。

原始教材當時提到新使用者可獲得限時點數；點數數量、有效期限與可使用模型均屬促銷資訊，請以產品頁面當下公告為準。

## 2. 開始對話

原始教材描述的介面提供數個預設助理角色。不同版本的名稱及數量可能改變，概念大致如下：

| 預設助理 | 用途 | 使用方式 |
|---|---|---|
| AutoClaw | 通用助理 | 直接描述目標與預期成果 |
| 研究助理 | 深度資料研究 | 填入研究主題，要求多角度檢索及交叉查證 |
| 監控助理 | 定時提醒或監控 | 說明時間、監控對象及提醒條件 |
| Browser Agent | 瀏覽器操作 | 明確描述要瀏覽的網站、操作步驟與輸出格式 |

上游教材也提到可以在對話中附加檔案或貼上 URL，讓助理讀取內容。使用前請確認檔案上傳後會送往何處、保存多久，以及是否會交由第三方模型處理。不要上傳身分證件、病歷、帳務資料或其他不必要的敏感內容。

### 2.1 研究助理提示詞範例

> 我想針對以下主題進行深入研究：【填入研究主題】。請協助我：
>
> 1. 從不同角度拆解問題。
> 2. 搜尋中英文資料來源，並交叉核對重要數據。
> 3. 區分已確認的事實、合理推論與尚待查證的資訊。
> 4. 產出架構清楚、引用來源完整的研究報告。

### 2.2 定時監控提示詞範例

> 請建立一項定時任務，每天【時間】整理【監控對象，例如股票代號】的最新資訊，並提供【需要的指標或摘要】。若資料來源無法取得，請明確標示，不要自行補值。

建立定時任務前，應確認時區、執行頻率、資料來源及可能產生的 API 費用；涉及交易或對外操作時，應保留人工確認。

### 2.3 Browser Agent 提示詞範例

> 請前往【指定網站】搜尋【主題】，依照【篩選條件】挑選五筆資料，整理標題、摘要、來源連結及可公開取得的互動數據，最後輸出成 Excel 檔案。

請遵守網站服務條款及著作權規範；不要要求代理程式繞過登入、付費牆、驗證碼或存取控制。

## 3. Quick Setup：設定助理的基本資訊

上游教材描述的初次設定卡片稱為 Quick Setup。其欄位包括：

| 欄位 | 說明 | 填寫建議 |
|---|---|---|
| What should we call you? | 使用者希望被如何稱呼 | 可填暱稱 |
| Your role | 使用者角色或職業 | 只填與任務相關的資訊 |
| What should I be called? | 替助理命名 | 可使用自訂名稱 |
| Focus areas | 助理專長 | Coding、Writing、Data Analysis、Research 等 |
| Working Directory | 工作目錄 | 確認路徑及目錄權限 |
| Restrict File Access | 限制檔案存取 | 建議開啟，並只授予必要資料夾 |
| Optimization Plan | 實驗性最佳化設定 | 未了解作用前維持預設值 |

完成設定後，請再次檢查工作目錄和檔案存取範圍。工作目錄不一定等同安全沙箱；若工具仍能使用絕對路徑或執行 Shell 命令，仍可能接觸其他檔案。

## 4. 點數或額度用完時

上游教材提到可透過介面購買點數。這是第三方服務的付費方式，並非 OpenClaw 本體的必要功能。

本網站不建議為了完成 OpenClaw 入門而先充值。若你的目標是低成本或本機使用，可先閱讀[第 5 章：模型管理](/adopt/chapter5/)，了解本機推論與不同模型供應商的設定方式；實際費用仍應以供應商最新價格為準。

## 5. 其他介面功能（依上游教材整理）

以下功能名稱取自原始教材中的介面描述；實際版本可能不同。

### 5.1 助理頭像

上游教材描述可從預設風格（例如 Cute Cat、Cyberpunk、Watercolor、Pixel Art、Anime Style、Minimalist）選擇頭像，也可輸入文字描述產生頭像。若使用外部圖片生成服務，請先確認圖片是否會上傳至第三方。

### 5.2 建立更多助理

原始介面可透過新增按鈕建立其他助理，並支援重新命名、變更圖示、置頂或刪除。刪除前應先確認是否連同對話紀錄、設定與檔案一起移除。

### 5.3 連接聊天平台

原始教材以飛書／Lark 作為範例，從 **IM Channels** 進入 **Connect IM Channels**，再依平台指引完成授權。

這是第三方桌面產品的整合流程，不等同於直接設定 OpenClaw 官方渠道。若要設定 OpenClaw 原生渠道，請參考[第 4 章：連接聊天平台](/adopt/chapter4/)。

### 5.4 定時任務

原始介面提供 **Cron Jobs** 頁籤，用於查看已建立的排程。建立任務後，應確認時區、下一次執行時間、失敗通知與停止方式。

### 5.5 Preferences 設定

原始教材提及以下設定分類：

| 分類 | 上游教材描述的功能 |
|---|---|
| General | 帳號安全、主題、登入時啟動、是否顯示工具呼叫 |
| Usage | 會話數、訊息數、Token 用量統計 |
| Points | 點數餘額、儲值及交易紀錄 |
| Models & API | 內建／自訂模型、Gateway URL、連接埠 |
| MCP Servers | 新增外部工具服務及常用範本 |
| Skills | 管理預裝技能與額外技能目錄 |
| IM Channels | 管理已連接的聊天平台 |
| Workspace | 工作目錄、檔案權限、自動保存上下文、檔案監看 |
| Data & Privacy | 查看資料儲存位置及隱私相關資訊 |
| Send Feedback | 回報問題；送出前留意是否會附帶日誌 |
| About | 查看版本與更新 |

**特別注意：** 回報問題可能自動附上本機日誌。日誌有機會包含路徑、帳號識別資訊、請求內容或錯誤上下文，送出前應先檢查是否包含機密資料。

## 6. 本章小結與替代路徑

AutoClaw 類型的桌面產品可降低安裝門檻，但通常會把模型、帳號、點數、工具及更新流程整合在供應商自己的產品中。這種便利性與可攜性、透明度及自行控制資料處理方式之間，需要自行取捨。

若你希望：

- 使用非中國開發的模型；
- 以開源工具及本機部署為主；
- 自行選擇模型供應商，避免綁定點數或單一服務；
- 了解每項工具的權限及資料流向；

建議直接從[第 2 章：手動安裝 OpenClaw](/adopt/chapter2/)開始，並搭配[第 5 章：模型管理](/adopt/chapter5/)設定模型。
