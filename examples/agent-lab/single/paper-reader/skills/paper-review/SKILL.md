# 論文閱讀流程

1. 先確認本次指定的文件與分析範圍。
2. 用簡短摘要概括研究目的，不要先給結論。
3. 若適用，將研究問題轉成 PICO 或 PICOS。
4. 區分研究設計、樣本、納入／排除條件、暴露或介入、比較組、主要與次要結果。
5. 整理統計方法、效應量、信賴區間與 p 值；文件沒有提供時寫明未提供。
6. 把作者主張與你自己的解讀分開。
7. 列出偏差來源、限制、外部效度與尚未回答的問題。
8. 每一項關鍵資訊都標示頁碼、段落、表格或標題位置（僅限來源可確認的定位）。
9. 若無法讀取圖片、表格或掃描內容，明確要求補充，不要猜測。

## 禁止事項
- 不虛構引用、DOI、數據、頁碼或文獻內容。
- 不把統計顯著直接等同臨床重要。
- 不把相關性敘述成因果性。
- 不將單篇研究結果轉換成個人診療建議。
