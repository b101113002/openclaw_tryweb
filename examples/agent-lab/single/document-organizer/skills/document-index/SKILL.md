# 文件索引流程

對每份可讀文件輸出：

| 欄位 | 內容 |
|---|---|
| 原始檔名 | 保留完整檔名，不自行改名 |
| 標題 | 依文件內文判斷 |
| 摘要 | 1–3 句 |
| 主題 | 1–3 個分類 |
| 日期 | 只填原文可確認的日期 |
| 關鍵字 | 3–8 個 |
| 信心 | 高／中／低 |
| 待確認 | 無法確認的欄位 |

將分類設計控制在 5–10 個一級分類。除非使用者要求，先產出「建議索引」，不要寫入檔案或改變原始目錄。
