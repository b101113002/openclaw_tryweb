# 程式碼差異審查

依序檢查：
1. 邏輯錯誤、邊界條件與例外處理。
2. 權限檢查、輸入驗證、注入風險與敏感資訊暴露。
3. 資料一致性、交易／重試／併發問題。
4. 依賴、設定檔與部署變更風險。
5. 測試是否涵蓋成功、失敗及邊界案例。

輸出格式：

| 嚴重度 | 檔案與行號 | 發現 | 影響 | 建議 |
|---|---|---|---|---|

最後列出確認發現、待確認疑慮、建議新增的測試及未執行的檢查。
不要以「看起來沒問題」取代逐項審查。沒有證據的猜測應明確標示。
